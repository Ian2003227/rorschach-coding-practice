# 部署後端（Google Apps Script + Sheets）

後端負責兩件事：帳號（暱稱 + 個人密碼）和每個人的作答紀錄。資料存在 Google Sheet 的三個分頁：

- `users`：暱稱、註冊時間、加鹽雜湊過的密碼（**不會存明文密碼**）
- `records`：每次作答紀錄（誰、哪一題、答案、各欄位對錯）
- 舊版留下的 `attempts`、`flags` 分頁已不再使用，可以直接刪掉

## 更新既有的後端（網址不變）

1. 打開原本那份 Google Sheet →「擴充功能」→「Apps Script」。
2. 把 `Code.gs` 的全部內容貼進去，取代舊內容，存檔（Ctrl+S）。
3. 左側齒輪「專案設定」→ 拉到最下面「指令碼屬性」→「新增指令碼屬性」：
   - 屬性：`ACCESS_CODE`　值：通關密語
   - 按「儲存指令碼屬性」
4. 右上角「部署」→「管理部署作業」→ 點現有部署的鉛筆圖示 →「版本」選「新版本」→「部署」。
   網址不會變，`js/config.js` 不用改。

`TOKEN_SECRET` 屬性會在第一次有人登入時自動產生，不用手動設定。刪掉它等於讓所有人登出（重新登入即可）。

## 從零部署（新的 Sheet）

1. 開一份新的 Google Sheet →「擴充功能」→「Apps Script」，貼上 `Code.gs`，存檔。
2. 照上面第 3 步設定 `ACCESS_CODE`。
3.「部署」→「新增部署作業」→ 類型選「網頁應用程式」：「執行身分」選你自己，「誰可以存取」選「所有人」。
4. 把得到的 `https://script.google.com/macros/s/xxx/exec` 網址貼進 `js/config.js` 的 `GAS_WEB_APP_URL`，commit + push。

## 管理

- **有人忘記個人密碼**：在 `users` 分頁刪掉他那一列，他就能用同一個暱稱重新註冊（舊作答紀錄仍會接上，因為紀錄是用暱稱對應的）。
- **清空所有資料**：刪掉 `users` 和 `records` 分頁，下次有人使用時會自動重建。
